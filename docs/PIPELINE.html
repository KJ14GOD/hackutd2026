Static Analysis

deterministicTypeScriptno LLM
  • Sorts every file into program, layout, job script, or config by reading its contents.
  • Builds lookup tables first: file nicknames to real datasets, job steps to programs and files, transactions to programs.
  • Runs one scanner per system over each program: other programs, layouts, files, databases, IMS, MQ, CICS queues, screens, network, identity, time, batch, scheduler, external routines.
  • Records every connection with the file and line it came from. Names it can't read become unresolved, never guesses.
  • Rolls it up into a yes/no grid: which systems each program touches.

Runtime

GnuCOBOL containerno networkno values
  • Compiles the old programs and loads real copies of their files from sample data.
  • Replaces every outside system with a stub that answers the call and logs which system was touched.
  • Runs each program under several scenarios (normal day, bad records, month-end) and records which code ran.
  • Compares what ran against the static map: each connection is confirmed, added (static missed it), or never fired.

  version: 1

  touches:  { program, system, how: "static" | "observed" | "both" }[]
  coverage: { program, paragraphsTotal, paragraphsRun: string[] }[]
}

Semantic Analysis

LLMone call per programmust cite lines
  • Builds a context pack per program: its source, its layouts, its connections with runtime marks, its neighbors, code that never ran, and open items.
  • Reads every line and explains every connection on the checklist. Reports any connection the scanners missed.
  • Finds business rules (including rules stored in data), suspected old defects (reported, never fixed), and edge values from each field's limits.
  • Compares programs that share a file or table to find mismatches and conflicting rules.
  • Turns anything it can't decide into a specific question. Findings without a valid line citation are dropped.

semantic.json (validated with zod)
type Finding = {
  kind: "connection" | "missed-connection" | "rule" | "defect"
      | "edge-value" | "coverage-gap" | "mismatch"
  summary: string, evidence: string[]  // ≥1 "file:line", required
  confidence: "high" | "medium" | "low"
}
type Question = { id, program, text, evidence, options: string[],
                  blocks: "rewrite" | "cutover" | "none" }
type Semantic = {
  version: 1
  results:      { program, findings: Finding[], questions: Question[] }[]
  crossProgram: Finding[]
  notVerified:  { kind: "unresolved" | "never-fired" | "never-ran", ref }[]
  dropped:      { program, reason: "no-citation" | "bad-citation" | "schema" }[]
}
