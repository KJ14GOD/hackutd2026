# Research: Legacy Knowledge Agent (8090 track)

Background research for our HackUTD 2026 project: an agent that modernizes legacy code one isolated component at a time, and asks the right person on Slack or Teams whenever it can't tell which behavior is correct. Every answer becomes a test.
